## 범위

상류 FRED (미국 St. Louis Fed) 거시지표 vendor 를 **한국은행 ECOS Open API** 로
교체. 상류 `fred.get_macro_data` 와 **동일 시그니처** 로 router 가 vendor 교체만
으로 작동. Task 7b 는 vendor 모듈 신규 작성만 담당. router 연결은 Task 7d.

## 수행한 변경

### `tradingagents/dataflows/vendors/ecos.py` 신규

**인증:**
- `ECOS_API_KEY` 환경변수 요구. 없으면 `EcosNotConfiguredError` (VendorNotConfigured
  Error 상속) → 라우팅 레이어가 "vendor unavailable" 로 처리.
- `get_macro_data` 는 fail-safe — 키 없음 / vendor 에러 / 네트워크 실패 전부
  사람 읽기 쉬운 문자열 반환, 예외 전파 없음.

**지원 지표 (20여 개 alias):**
- **금리**: `base_rate` (기준금리), `call_rate`, `treasury_3y/10y`
- **인플레이션**: `cpi`, `core_cpi`, `ppi`
- **성장**: `real_gdp`, `industrial_production`
- **통화**: `m1`, `m2`
- **환율**: `usd_krw`, `jpy_krw`, `eur_krw`, `cny_krw`
- **노동**: `unemployment_rate`, `employment_rate`
- **심리**: `consumer_sentiment` (CSI), `business_sentiment` (BSI)

각 alias → `(STAT_CODE, CYCLE, ITEM_CODE)` 튜플 매핑. CYCLE 은 ECOS 코드 (`D`/`M`
/`Q`/`A`) 에 맞춤.

**모듈 수준 헬퍼:**
- `_resolve_series(indicator)` — alias → ECOS 코드 튜플. 미지원 지표는 명확한
  ValueError (LLM 이 설명 문구 넘기는 경우 안내).
- `_format_period(dt, cycle)` — datetime → ECOS 기간 문자열 (D: `YYYYMMDD`,
  M: `YYYYMM`, Q: `YYYYQn`, A: `YYYY`).
- `_parse_period(text, cycle)` — 역변환.
- `_fetch(stat_code, cycle, start, end, item_code)` — ECOS StatisticSearch 호출.
  URL 세그먼트 조립, HTTP 에러 체크, `RESULT.CODE` 에러 체크 (ECOS 는 에러를 HTTP
  200 유지한 채 payload 로 반환).
- `_format_value(raw)` — 숫자 포맷 (comma 구분, 범위별 소수점 조정).

**공개 함수:**
- `get_api_key()` — 환경변수 조회, 없으면 EcosNotConfiguredError.
- `get_macro_data(indicator, as_of_date, look_back_days)` — 상류 FRED 와 동일
  시그니처. Markdown 리포트 반환 (지표명, 사이클, 단위, 최신값, 변화량/변화율,
  최근 40개 관측 테이블).

**반환 형식:**
```markdown
## 한국은행 기준금리 (base_rate)

- **지표 코드**: 722Y001 / 0101000
- **단위**: %
- **사이클**: D
- **최근값** (20261101): 3.25
- **기간 시작** (20260501): 3.75
- **변화**: -0.5 (-13.33%)

### 관측 데이터

| 기간 | 값 |
|---|---:|
| 20260501 | 3.75 |
| 20260801 | 3.50 |
| 20261101 | 3.25 |
```

### `tests/test_ecos_vendor.py` 신규

**32개 테스트**, 전부 `get_scrubbed` 를 `patch` 로 모킹:
- 환경변수 체크 (키 없음 → typed error / fail-safe 문자열)
- 지표 매핑 (5개 alias parametrize, case-insensitive, 미지원 → ValueError)
- 기간 포맷 (6개 (dt, cycle) 조합 parametrize) + 역파싱
- 값 포맷 (4개 범위별 parametrize)
- 리포트 렌더링: Markdown 구조, 헤더/테이블/변화율 포함
- ECOS 에러 처리: 빈 rows / RESULT.CODE 에러 / HTTP 500 / 네트워크 예외
- 변화율 계산: `+10%` 포맷
- 역순 응답 정렬: 관측 테이블은 오래된 → 최신 순

## 설계 결정 변경 사항

### 상류 FRED 와 동일 시그니처

code_artifact.md 는 "ECOS 호출 또는 정적 매핑으로 교체" 명시. router 교체 비용을
최소화하기 위해 **동일 시그니처** (`get_macro_data(indicator, as_of_date,
look_back_days)`) 유지. Task 7d 에서 router 는 vendor 교체만으로 작동.

### Fail-safe 전략

`fred.get_macro_data` 는 ValueError 를 raise 하지만, ECOS vendor 는 분석가 중단
방지를 위해 **모든 에러를 Markdown 문자열로 변환**. 네트워크 블립이나 키 미설정이
run 을 중단시키지 않도록. 라우팅 레이어의 `OPTIONAL_CATEGORIES` 와 결합되어
macro 데이터 없이도 분석가가 진행 가능.

### 지표 세트 범위

code_artifact.md 는 "환율·기준금리 등" 만 예시. 분석가가 다양한 거시 신호를 활용
할 수 있도록 20여 개 alias 제공 — 상류 FRED 의 30여 개와 비슷한 커버리지. 한국
특화 지표 (CSI, BSI, 원/엔, 원/위안) 포함.

### CYCLE 매핑 vs vintage pinning

상류 FRED 는 `realtime_start/end` 로 vintage pinning (과거 특정 시점의 revision 반영).
ECOS 는 이에 대응하는 공식 파라미터가 없어 **생략** — ECOS 데이터는 revision 이
드문 편이고, 분석가 run 은 as_of_date 로 관측 창을 한정하는 걸로 충분.

### ``core_cpi`` 등 item_code 추정

ECOS 는 통계 코드 대비 item 코드 체계가 통계마다 다름. 공식 문서 없이 코드를
추정한 항목 (예: `core_cpi` 의 `QA` item) 은 Task 11 통합 테스트에서 실제 응답
확인 후 조정 가능. 유닛 테스트는 mock 으로 커버.
