## 수행한 변경

### `pyproject.toml`

**새 의존성 2개:**
- `OpenDartReader>=0.2` — Open DART API 래퍼. 0.3+ 는 py3.13+ 전용이라 CI 매트릭스 (py3.11/3.12) 호환을 위해 0.2 이상으로 완화. 두 버전의 패키지 레이아웃이 다름 (0.3: 소문자 `opendartreader`, 0.2.x: 대문자 `OpenDartReader` + `sys.modules` 교체 트릭) — dart.py 의 `_resolve_opendartreader_class()` 가 흡수.
- `tabulate>=0.9` — `pandas.DataFrame.to_markdown` 백엔드

### `tradingagents/dataflows/vendors/dart.py` 신규

**모듈 수준:**
- `_dart()` — lazy singleton. `DART_API_KEY` 환경변수와 OpenDartReader 라이브러리를 처음 호출 시점에 확인 후 인스턴스 생성. 캐시된 에러를 올려 상위 레이어가 fail-safe 로 처리 가능.
- `_reset_for_tests()` — 테스트용 재초기화 헬퍼.
- `_REPRT_CODES_BY_FREQ` — 분기(`11013` Q1 / `11012` H1 / `11014` Q3 / `11011` 연간) 매핑. 가장 최근 공시 순으로 fallback.
- `_latest_finstate` — `curr_date` 기준으로 가장 최근 공시된 (year, reprt_code, DataFrame) 을 반환. 올해/작년/전년 세 해를 순회.
- `_format_statement` — `finstate_all` DataFrame 에서 특정 재무제표 섹션 (BS/CIS/IS/CF) 을 Markdown 표로 포맷. 당기/전기/전전기 비교 포함.
- `_render_company_overview` — 기업 개황 dict 를 "회사명/대표자명/업종/설립일/주소" Markdown 리스트로.

**공개 함수 (상류 vendor 와 동일 시그니처):**
- `get_fundamentals(ticker, curr_date, trade_date="")` — 기업 개황 + 최근 분기 손익/재무상태 요약
- `get_balance_sheet(ticker, freq, curr_date, trade_date="")` — 재무상태표 (`sj_div == "BS"`)
- `get_cashflow(ticker, freq, curr_date, trade_date="")` — 현금흐름표 (`sj_div == "CF"`)
- `get_income_statement(ticker, freq, curr_date, trade_date="")` — 포괄손익(CIS) → 손익계산서(IS) 폴백
- `get_insider_transactions(ticker, trade_date="")` — `major_shareholders_exec` 임원·주요주주 지분변동
- `get_convertible_bonds(ticker, trade_date="")` **신규** — KRX 전용 지표. 최근 1년 공시에서 "전환사채" 가 제목에 포함된 것만 필터. CB 는 신주 발행 가능성이라 희석 리스크 평가에 중요.

**Fail-safe:**
- 모든 함수가 `OpenDartReader` 예외를 흡수해 `"[DART 조회 실패: ...]"` 같은 사람 읽기 쉬운 문자열 반환
- 분석가 선조회가 섹션 하나를 잃어도 run 자체는 완결됨 (Task 3 의 `_safe` 패턴과 호환)

### `tests/test_dart_vendor.py` 신규

**13개 테스트**, 전부 `opendartreader.OpenDartReader` 를 `patch` 로 모킹 (네트워크 호출 없음):

- `get_fundamentals` 섹션별 예외 흡수 (`company()` 실패해도 재무 섹션 유지)
- `get_balance_sheet` / `get_cashflow` 섹션 포맷

## 설계 결정 변경 사항

### `get_convertible_bonds` 신규 함수

code_artifact.md Task 5 에 "전환사채(CB) 발행 내역" 이 추출 지표로 명시되어 있으나 상류 vendor 에는 대응 함수가 없음. 신규로 `get_convertible_bonds` 를 추가해 Task 5b (fundamentals_analyst 전환) 가 CB 섹션을 프롬프트에 주입할 수 있도록 준비.

### `tabulate` 의존성 명시 추가

`pandas.DataFrame.to_markdown` 이 런타임에 tabulate 를 요구하지만 pandas 가 `[extra]` 로 제공하지 않음. 명시적으로 pyproject 에 추가.

### import 자체는 성공, 호출 시점에 에러

`DART_API_KEY` 가 없는 환경 (CI, 로컬 개발 시작 시) 에서도 모듈 import 는 성공해야 다른 테스트가 돌 수 있음. 그래서 `_dart()` 가 lazy 하게 생성하고 호출 시점에 명확한 에러.
