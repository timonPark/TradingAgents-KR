## 범위

웹에서 "분석 시작" 을 눌렀을 때 실제 `TradingAgentsGraph.propagate()` 를 백그라운드로 돌리고, LangGraph 노드 전환을 **라이브** 로 UI 에 밀어주는 전체 플로우.

이 티켓은 Task 14 에픽 안에서 **가장 범위가 큰 서브태스크** 이고, 코어 (TradingAgentsGraph) · 백엔드 (api/) · 프론트엔드 (web/) 세 곳을 모두 건드린다.

## 수행한 변경

### 1) 코어: `tradingagents/graph/trading_graph.py`
- 생성자에 `progress_callback: ProgressCallback | None = None` 추가
- `_PROGRESS_LABELS` 테이블 — 리포트 state 키 ↔ 한국어 라벨
- `_run_graph` 안에서 `run_start` → (debug=True 일 때 `node_complete*`) → `done` emit
- `_emit_progress` 헬퍼 — `getattr` + `callable` 가드로 테스트 더블·MagicMock 모두 안전

### 2) 백엔드: `api/`
- `run_store.py` — 인메모리 `RunStore` (run_id → `RunState` + `asyncio.Queue`)
- `runner.py` — `asyncio.run_in_executor` 로 propagate 를 별도 스레드에서 실행, `call_soon_threadsafe` 로 이벤트 안전 전달
- `routes/runs.py`
  - `POST /api/runs` — 새 run 생성 (ticker 6자리 regex, trade_date YYYY-MM-DD, 분석가/모델/effort)
  - `GET /api/runs` — 최근 목록 (사이드바 전구)
  - `GET /api/runs/{id}` — 상태 스냅샷
  - `GET /api/runs/{id}/events` — `sse-starlette` SSE, 기록된 이벤트 replay 후 큐에서 push, done/error 시 닫힘
- `main.py` — runs 라우터 등록

### 3) 프론트엔드: `web/`
- `components/RunPanel.tsx` — 전체 종목 선택 + 설정 + 실행 + 라이브 패널
  - 내부적으로 14d 의 `SymbolSearch` 를 감싸 선택을 수신
  - 날짜 (기본 오늘·KST), 분석가 체크박스 (4개), deep/quick 모델 (sonnet/opus/haiku), effort (low..max)
  - "분석 시작" → POST /api/runs → EventSource → 노드별 chrono step 렌더
  - 완료 시 `결정: <rating>` 표시, 에러 시 vermilion 토스트
- `components/RunPanel.css` — Impeccable 토큰만 사용 (kinpaku 완료 표시, patina 라이브 글로우 + 펄스)
- `pages/index.astro` — hero 안에 `<RunPanel client:load />`

## 설계 결정

### 노드 전환 캡처: 코어의 `stream_run` 기반 state-diff
- 기존 `stream_run` 이 LangGraph `graph.stream(stream_mode=["values","tasks"])` 을 돌리고 `(messages, state)` 를 yield 하고 있어 그걸 재활용
- `_run_graph` 안에서 `final_state` 가 업데이트될 때 `_PROGRESS_LABELS` 에 없는 새 키가 들어오면 `node_complete` emit
- **node_complete 는 debug=True 일 때만** — 비-debug 경로는 `graph.invoke(...)` 한 번으로 끝. 웹 UI 는 `debug=True + progress_callback=emit` 조합으로 넘긴다 (api/runner.py)

### `invoke` 경로 유지 (리그레션 회피)
- 기존 테스트 2개가 `MagicMock` 과 `object.__new__` 로 생성된 더블 사용 — `progress_callback` 유무에 분기점을 두지 않도록 **`stream_mode = self.debug`** 로 좁힘. 이 PR 전후로 비-debug 경로의 바이트 수준 동작 동일

### 백그라운드 실행: `asyncio.run_in_executor`
- `TradingAgentsGraph.propagate` 는 동기 함수. 로컬 전용이라 큐/워커 풀 없이 `None` 기본 executor 로 충분
- 콜백에서 큐 push 시 `loop.call_soon_threadsafe` 로 main 루프로 안전 전달

### 인메모리 저장소 (DB 없음)
- 로컬 전용이라 프로세스 수명 동안만 유지. 재시작 후엔 run 이력 소실 — 리포트 파일 (`~/.tradingagents/results/`) 은 디스크에 남으므로 14f 가 거기서 복원

### SSE replay
- GET events 가 늦게 연결돼도 지금까지의 이벤트를 **전부 다시 밀어주고** 현재 큐로 이어진다. UI 재연결 시 상태 복구 간단

### 설정 폼 범위
- CLI 와 **등가** 선택지: 분석가 4종 토글, 모델 3종, effort 5단계, 날짜 picker. 백테스트/체크포인트 플래그는 미노출
