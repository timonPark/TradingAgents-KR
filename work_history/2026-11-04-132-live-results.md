## 수행한 변경

- 완료 이벤트를 실제 task 완료 경로로 통합. state-diff 중복 이벤트 제거.
- 노드별 반환 필드에서 이번 호출의 본문 추출. 토론 누적 기록을 재출력하지 않으며 반복 라운드는 각각 표시.
- 내부 agent/Memory Log 제외. 실제 그래프의 Sentiment Analyst 및 리스크 노드 이름 사용.
- API 리포트 저장 후 `report_saved` → `done` 순서로 전달. 저장 실패는 오류로 종료.
- SSE 구독자별 이벤트 커서 적용: 늦은 접속의 중복과 복수 구독자의 이벤트 유실 방지.
- 라이브 패널에 MD/HTML/PDF 다운로드와 뷰어 링크 추가, 기본 effort=low.
- 실행 URL `?run=...`로 새로고침 후 결과 재조회. 병렬 분석가의 진행 상태 유지.
- 구조화 출력 입력의 role/content 딕셔너리를 LangChain 메시지로 변환.
- pykrx가 지원하지 않는 vwma 요청 제거.

## 설계 결정 변경 사항

기존 라이브 본문 구현의 state-diff 감지를 task 완료 감지로 교체했다. UI 요구 범위는 동일하며 ADR의 LLM 공급자와 사전조회 구조는 유지한다.
